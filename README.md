# rental-property-check(賃貸物件チェック)

賃貸物件の URL や間取り図、重要事項説明書を Claude に渡すと、**住んでから後悔しそうな点を、内見や契約の前に洗い出す** Claude Code のスキルです。

## なぜ作ったか

自分の引っ越しの物件探しで、リビングの窓の正面にある生コン工場や、バルコニーの正面にある自動車整備工場を、内見に行くまで見落としました。原因は2つありました。

- 地図で周辺を調べるときに、自動車整備工場などを検索語に入れていなかった
- 窓の向きを、募集図面の「南向き」という表記で判断していた(間取り図の方位記号で見ると南西だった)

物件を1件ずつ自分で調べると、こうした見落としが起きます。そこで、確認の手順と計算を Claude に任せられるようにしました。

## できること

| 観点 | 内容 |
|---|---|
| 周辺の騒音・粉じん源 | 工場・整備工場・倉庫・車庫・幹線道路などを地図と航空写真で探し、**間取り図の方位記号から求めた窓の向き**に対して、正面か斜めか、何mかを計算する |
| 子育て環境 | 徒歩圏の保育園の数と徒歩分数、認可かどうか、入所可能数とボーダー指数、延長保育の時刻、申込の締切と転入の条件 |
| 希望条件との照合 | 賃料・広さ・駅徒歩・築年数・定期借家の残り期間 |
| 費用 | 初期費用の合計と内訳(戻らないお金/家賃の前払い/敷金)、毎月の支払い |
| 建物・住戸・契約 | 新耐震、遮音、冷蔵庫置き場、エアコンが設備か残置物か、特約、短期解約違約金など |

結果として、次のものが出てきます。

- 見送るかどうかの判断(明らかにダメな物件は、最初の段階で見送り候補にして終える)
- 交渉材料と交渉の順序
- 内見で確認するリスト(採寸箇所、各窓から見えるもの、保育園まで歩く経路)
- 不動産会社への確認質問メールの案

## 仕組み

- **二段構え**:段階1(一次判定)で見送りになれば、そこで終える。通過した物件だけ、段階2で詳しく調べる
- **計算は暗算しない**:距離・方角・費用・期間・保育園の集計は、`scripts/calc.py`(Python、標準ライブラリのみ)で計算する
- **保育の情報は自治体ごとに手元に保存する**:使う人の市区町村の公式資料を調べて `local/` に「自治体メモ」として保存し、古くなったら(年度替わり、申込時期など)更新する

```
rental-property-check/
├── SKILL.md                # Claude への手順書(スキル本体)
├── criteria.example.md     # 希望条件のひな形
├── references/
│   ├── criteria.md         # 希望条件の読み方
│   ├── kids.md             # 保育園の調べ方と自治体メモの更新
│   ├── checklist.md        # 建物・住戸・契約条件のチェックリスト
│   └── portal-reading.md   # SUUMO などの読み方
└── scripts/calc.py         # 距離・方角・費用・期間・保育園の計算
```

## 使い方

### 1. スキルとして置く

このリポジトリを、Claude Code のスキルのフォルダに置きます。

```bash
git clone https://github.com/k-dev-log/rental-property-check.git ~/.claude/skills/rental-property-check
```

### 2. 希望条件を書く

ひな形をコピーして、自分の条件に書き換えます。

```bash
cd ~/.claude/skills/rental-property-check
cp criteria.example.md criteria.md
```

`criteria.md` を用意しなくても使えます。その場合は、チェックのたびに Claude が条件を質問します。

### 3. 物件を渡す

Claude Code に、物件の URL や資料を渡して頼みます。

```
この物件どう? https://suumo.jp/chintai/...
```

```
内見前に確認して(間取り図と重要事項説明書を添付)
```

## 動作に必要なもの

- Claude Code
- Python 3(`calc.py` の実行用)
- Claude in Chrome(SUUMO のページや航空写真を読むため)
- あれば地図検索のツール(なければ Chrome で Google マップを検索します)

## 個人情報について

希望条件(`criteria.md`)、自治体メモ(`local/`)、物件の資料(`properties/`)は `.gitignore` に入っていて、git に記録されません。fork して使う場合も、自分の条件が公開されることはありません。

## 注意

- 結果は判断の材料です。最終的な確認は、内見と重要事項説明書で行ってください
- 法律の助言ではありません
- Google マップに載っていない作業場は、検索では見つかりません。窓の方向は、航空写真・ストリートビュー・内見で確かめてください
