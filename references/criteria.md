# 希望条件の読み方

## 正本は criteria.md
- 希望条件は、このスキルのベースディレクトリ直下の `criteria.md` に書いてある(ひな形は `criteria.example.md`)
- `criteria.md` は使う人の個人情報なので、内容を外部に送らない。報告には「今回使った基準」の1行だけを書く
- 「数値基準」の表を読み、次のように `calc.py` へ渡す

| criteria.md の行 | 渡す引数 |
|---|---|
| 賃料上限(管理費込み・円) | `screen --max-monthly` |
| 専有面積(㎡以上) | `screen --min-area` |
| 駅徒歩(分以内) | `screen --max-walk` |
| 築年数(年以内) | `screen --max-age` |
| 定期借家の最低期間(ヶ月) | `screen --min-term`、`term --min-months` |
| 入居希望日 | `term --move-in`、`cost --move-in` |
| 園まで徒歩の上限(分) | `kids --max-walk-min` |
| 徒歩圏に必要な園数(認可・小規模) | `kids --min-count` |
| 延長保育の必要時刻 | `kids --need-until` |

- 「子育て(保育園)」の残りの行(申込先の市区町村、入園予定、年齢クラス、指数、申込の状況)は `references/kids.md` の評価に使う
- 「数値以外の条件」(エリア、通勤先、周辺環境の方針、部屋の使い方、家具の寸法など)は、段階2の評価と内見リストに使う

## 報告に書くこと
- 今回使った基準を1行で書く(例:賃料上限20万円/55㎡以上/徒歩10分以内/築25年以内/定期借家24ヶ月以上/入居4月1日想定/保育園は徒歩10分以内に認可・小規模3園以上、延長19時まで)
- ユーザーが会話の中で基準と違う条件を言った場合は、その会話の条件を優先し、報告に「今回は会話の条件で判定」と書く

## criteria.md がないとき・空欄があるとき
- `criteria.md` がなければ、ユーザーに「`criteria.example.md` をコピーして条件を書くと、次回から自動で読めます」と伝える
- 今回の判定に必要な数値基準(賃料上限・面積・徒歩・築年・定期借家の最低期間・入居日)を、1つの質問にまとめて聞く。子育ての条件は、保育園を気にするかどうかも含めて同じ質問で聞く
- 既定値で判定しない。答えがなかった項目は判定から外し、報告に「未設定のため判定せず」と書く
- ユーザーが望めば、聞いた値で `criteria.md` を作る(ひな形の形式に合わせる)
